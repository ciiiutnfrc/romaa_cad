# Modelo del robot RoMAA con FreeCAD

Los archivos del modelo son:

- `RoMAABottom.FCStd`: placa base.
- `RoMAATopFront.FCStd`: placa superior delantera.
- `RoMAATopRear.FCStd`: placa superior trasera.
- `RoMAASensorBar.FCStd`: barra para montaje de sensores.
- `RoMAAMainColumn.FCStd`: columnas principales.
- `RoMAASecondaryColumn.FCStd`: columnas secundarias.
- `RoMAAWheel.FCStd`: ruedas de tracción.
- `RoMAACastorSupport.FCStd`: soporte de rueda castor.
